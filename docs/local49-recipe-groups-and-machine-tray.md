# local.49 · 相同配方合并与全部机器图标浮层

日期：2026-10-26。保留 local.47 / local.48 未提交工作区改动，不自动部署。

## 根因与修复

此前 RouteJeiRecipes.collect 将 JEI 返回的每项直接加入 recipes，图标轮换只处理单个条目自身的 catalyst 列表。轮换不等于去重，所以同一配方在多个机器分类下仍可能占多行。

本轮先对全部返回项分组，再以一组一行生成列表、分页和计数：

- 原生 Recipe / RecipeHolder：注册表感知的 Recipe.CODEC 完整数据作为语义指纹，允许不同注册 ID 的等价原生配方合并；serializer/type、耗时、经验、能耗等被配方 codec 编码的字段仍参与比较。
- 其他 JEI 对象：以实际对象类和 JEI 提供的精确配方注册 ID 作身份；没有可靠 ID 的条目保留独立行。
- 身份之外，还比较全部 INPUT/OUTPUT 槽的完整组件 key、数量及全部替代项；替代项顺序规范化，但槽位顺序保留。不仅比较当前轮播出来的材料，也不按“合成”等标题或产物名称合并。
- 特殊动态配方、无法序列化、原生布局创建失败或材料无法转换的条目不强行合并。
- 合并全部成员的机器 catalyst，按 JEI typed ingredient 的完整 UID 去重；保留首项原生布局和全部成员 ID 的聚焦别名。

## 悬停交互

JEI 配方列表、右侧配方头部和 JEI 画布机器图标继续约 3 秒轮换。鼠标移到图标上，弹出全部候选机器图标网格；可移入浮层逐个悬停看名称、点击查询该机器自身配方。浮层在窗口边缘避让，设备多到超出屏幕时可滚轮查看其余行，不静默截掉设备。

浮层绘制在节点菜单上方，点击/滚轮先经过浮层命中检查，再交给背后的菜单、原生 JEI 布局或画布，避免误选配方、缩放或改数量。画布缩放下的图标坐标通过当前 pose 转成屏幕坐标后定位浮层。

本轮浮层针对 JEI catalyst 机器候选；local.48 原生 AE 供应器来源仍按真实供应器元数据展示，不将其与 JEI 的可用机器候选混为一谈。
