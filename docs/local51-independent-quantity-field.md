# local.51 · 独立数量行、输入与滚轮并存

日期：2026-10-26。延续 local.47–50 未提交改动，未部署到正式实例。

## 呈现

数量由物品角标移到图标下方独立行：物品/机器区 y=4 起，数量行 y=36..52，名称 y=56，状态/EMC 成本 y=70，节点高 84px。输入行与物品主图标、机器徽标、名称均不重叠。数量用完整整数显示而非 k/M 缩写，长数按可用宽度缩小；输入草稿用白字和独立焦点背景，不冒充已证明数量。

RouteQuantityField 负责几何、热区、滚轮意图和输入缓冲步进；RouteScreen 仅取数绘图与调用。树布局和碰撞约束使用新节点高度，不把数量行挤进旧 62px 卡片。

## 操作

- 左击数量行输入，初始全选式替换；再次点击当前编辑行不会重置已输入内容。
- 支持 Ctrl+A、Ctrl+V（仅 1..15 位数字）、Backspace、Enter 确认、Esc 取消；原中键输入仍可用。
- 数量行上直接滚轮按配方批量增减，Shift 按一个单位；无已知配方批量时按一个单位。
- 输入中滚轮使用当前输入值继续增减，不退回旧的模型数量。全部留在缓冲区，Enter 一次应用，Esc 一起取消。空缓冲滚轮从当前派生需求开始。
- 未进入输入模式时滚轮仍即时调整，沿用原撤销机制。
- Ctrl+滚轮越过数量热区走原缩放逻辑，水平滚轮走原平移逻辑。数量行外保留默认缩放、Alt 数量以及 scrollEditsQuantity 旧习惯开关。
- 搜索建议、节点菜单、机器候选浮层与供应器抽屉保持输入优先级。回料引用数量仍只读。
- 最终产物数量改变会触发原有权威预览；其他节点数量继续是本地覆盖，未偷偷提交服务端。
