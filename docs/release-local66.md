# AE-Craftroute 1.13.19-local.66-dev

## 变更原因

将本轮规划性能、进度反馈与派发所有权加固发布为独立版本，避免与 local.65 同名而无法识别实际运行构建。

## 修复与加固

- 规划器输入、输出与净变化采用稀疏数量表示；前驱计算只更新相关材料，保留完整认证重放。
- 修复无种子替代路线造成的虚假需求，以及启动阶段消耗目标库存后无法及时捕获低水位增产循环的问题。
- 增加有界 SCC 区域候选，汇总共享需求；仅对单输出、唯一生产者语义使用，未成功时继续通用求解，不能误报缺料。
- 画布规划新增服务端节流进度更新，显示阶段与耗时，并丢弃过期请求更新。
- 原生及 AdvancedAE 派发共用一次性所有权事务，防止嵌套钩子重复推进；新增可选 CraftRouteDispatch.confirmAccepted 接收回执。
- 已确认接收后的普通清理异常保留成功结果，未知所有权异常不伪装成可退款拒收。

## 文档

- docs/aelis-implementation-status.md：实施范围、测试证据与未完成项。
- docs/certified-dispatch-ownership.md：供应器回执、异常处理及同步回料边界。

## 验证

- 单元测试与功能测试各 674 项，零失败；构建通过。
- 独立真实服务端回执：PASS task=rejectonce、PASS task=advanced。
- rejectonce 是请求方首次拒收最终交付的场景，不等同于供应器 pushPattern 拒收测试。
- 新增异常、同步回料和 NBT 场景为模型/单元验证，未声称完整第三方供应器矩阵通过。

## 限制

- 本次不是全部研究方案的完成版：库存租约、端到端 BigInteger 订单、第三方追加批量与性能基准仍待实施。
- 继续隔离未经验证的外部批量；未提前登记待回收量，同步未被接收的产物仍需供应器保留重试。
- 没有真实整包性能提速百分比或客户端视觉验收结论。客户端与服务端应使用同一版本。

附件含成品、源码包及 SHA-256。上一版本包已保存在前一发布，不要同时安装多个版本。
