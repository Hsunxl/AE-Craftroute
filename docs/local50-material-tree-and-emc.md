## 对应五项反馈

1. **机器不独立成节点**：不再绘制独立机器框，父材料直接连子材料。RNode 仅保留配方数据/内嵌图标位置，已删除独立机器拖动分支，不改样板身份和路径。
2. **图标替代加号且轮换保留**：材料右上角为 18px 获取方式图标，随材料位置移动。已选配方显示 JEI 机器、真实 AE 供应器来源或 EMC 转换设备；尚未选择时用空白样板作选择入口，不猜机器。图标单击进入配方详情，右键仍可选配方。网络来源新增路径级轮换状态，JEI/网络/EMC 均保留约 60 tick 轮换与悬停全部候选网格；折叠后配方图标仍在。
3. **拖父节点带动子树**：按下鼠标时捕获整树几何，拖动使用绝对鼠标位移，不逐帧累加，路径段边界区分 root/1 与 root/10。父偏移通过递归继承，隐藏/折叠后代再展开也沿用父位移。松开时把所有受影响节点位置转换为父相对偏移，只产生一次撤销快照。
4. **层级与防重叠**：纯函数 RouteTreeGeometry 分层求解。同层节点边界至少间隔 16 个世界坐标像素；下一深度层的顶边不高于上一层所有节点最大底边 + 28px。碰撞修正移动对应整棵子树；邻近分支必要时被推开，而非允许节点自由交叠。布局重建、拖动、拖材料落点都复用约束。
5. **EMC 成本与设备统一呈现但不混账**：核对本地 AppliedE 1.0.8-beta jar，EMCKey 类型 ID 是 appliede:emc，为数值资源，不是机器。无配方、非回料引用的 EMC 叶子只在视图中收进父材料“网络 EMC”成本行，逻辑节点、完整 inputs、原始 childPath 和服务端应用遍历均保留。有实际生产配方或循环引用的 EMC 仍显示依赖，不隐藏真实生产链。ProjectE EMC 获取方式显示单价/总成本与转换桌、转换台图标，设备参与轮换/悬停网格；EMC 数值资源从 JEI 机器 catalyst 中排除。

## EMC 边界

AE 网络 EMC、ProjectE 玩家个人余额和学习状态是不同数据源。此次统一的是获取方式的视觉与入口，不把两个库存池相加，不凭“物品有 EMC 值”宣称可执行自动合成，也不把数值键当作转换桌机器。转换桌/转换台 ID 分别为 projecte:transmutation_table / projecte:transmutation_tablet，真实物品显示名仍由游戏提供。
